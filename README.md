An entry for make.fun's [token-radar-01](https://make.fun/c/token-radar-01) bounty: a radar that finds the protocols whose token does not exist yet, ranks them by what that token would be worth, and tells a reader exactly how to farm each one.

## The one idea

Rank by **pure implied value only**. An earlier version blended the rank 50/50 with token odds and fell to #7289; the pure-implied-value version ranked #1979. Token odds are weak at predicting future launches (temporal AUC 0.61, near random — most of the signal is a cohort effect: old protocols are more likely to already have a token). So v7 shows token odds as information and never lets them move a rank.

## The model

Log market cap fit by least squares on the 128 live protocols that record a market cap:

```
log mcap = 6.910 + 0.519 x log(TVL) - 0.135 x clipped 7-day change
```

The 7-day change is the snapshot's per-cent figure clipped to [-1, 3]. The implied value of a pre-token protocol is exp(predicted log mcap), rounded to whole dollars.

Feature selection was earned on two blind tests per candidate (error = median multiplicative factor):

| Feature set | Leave-one-out | Walk-forward 2025-01-06 | Walk-forward 2025-06-01 | Worst WF |
|---|---|---|---|---|
| **A — logTVL + clipped change** | **3.509x** | **2.917x** | **4.923x** | **4.923x** |
| B — A + age capped at 1 year | 3.553x | 2.917x | 4.923x | 4.923x |
| C — A + uncapped age | 3.657x | 5.053x | 3.912x | 5.053x |

B ties A on worst-case walk-forward (its capped-age column is constant in both walk-forward train sets, so it predicts exactly as A does) and loses the leave-one-out tie-break. C loses outright: uncapped age is a cohort effect, not a predictor. Set A wins, so age is not a feature of the fitted model — it is still shown on the dashboard, and it defines the peer group for the token-odds column.

## Coverage

All 758 protocols are accounted for: **330 ranked** launch candidates, **158 live** (already record a token, shown with the market's own market cap, never modelled), **270 tracked** pre-token protocols that are not launch candidates (versioned names, wrapped/staked/bridged products, exchanges) with the reason each is excluded. All 40 watchlist slugs are ranked.

## Farm verdicts

Each ranked row carries FARM / THIN / SKIP with $/hour, expected share, break-even and minimum capital, from stated assumptions: a 5% airdrop pool, farmer count from TVL at a $2,000 typical deposit, gas on the cheapest chain for 12 transactions, 4 active hours. FARM at $10/hour or more, THIN at $2/hour or more, else SKIP. Every row carries 6 concrete farm steps with a cost and a time each. The peer token share (share of same-age protocols that already record a token) is shown for information only.

## Run it

Node 22, standard library only, deterministic and offline:

```sh
node main.ts --input <snapshot.json> --output <out dir>
```

It writes `board.json`, `data.js`, `dashboard/`, `screenshots/` and `dossier.json` into the output directory. Two runs write the same bytes (verified).

## Layout

- `main.ts` — entrypoint
- `lib/model.ts` — the fit, the feature-selection tests, farm economics, farm-plan templates
- `dashboard/` — `index.html`, `app.css`, `app.js`; `data.js` is generated by `main.ts`
- `vendor/makefun-board.ts` — the kit's dossier library, copied byte for byte
- `screenshots/` — board, detail, filtered views of the dashboard
